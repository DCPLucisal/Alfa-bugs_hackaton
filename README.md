Название команды: Альфа-жуки

Умный кредитный кабинет для МСБ (Альфа-Бизнес)

Назначение решения
Прототип цифрового кредитного конвейера для малого и микробизнеса. Решение объединяет клиентский путь (от входа в кабинет до получения денег) и внутреннюю логику банка (скоринг, ИИ-ассистент, работа андеррайтера). Главная цель — сократить время оформления заявки, сделать процесс прозрачным для клиента (стресс-тест, статусы) и дать менеджеру умный инструмент для принятия решений с помощью ИИ.

Архитектура
Frontend: Vanilla JavaScript (ES6), HTML5, Tailwind CSS (CDN). Состоит из 8 экранов (SPA).
Backend: Python 3.11, FastAPI. Реализует REST API, логику скоринга, работу с БД и интеграцию с LLM.
Database: PostgreSQL 15. Хранит данные клиентов, компаний, заявок, результаты скоринга и логи ИИ.
AI (LLM): Локальная модель qwen3.5:4b через Ollama. Используется для генерации объяснений скоринга и резюме для менеджера (с защитой от галлюцинаций через Guardrails).
Infrastructure: Docker, Docker Compose.

Требования к окружению
Docker Desktop (или Docker Engine + Docker Compose).
Ollama (запущенная локально на порту 11434 с моделью qwen3.5:4b).
Любой современный браузер (Chrome, Safari, Firefox) с поддержкой ES6.
Опционально для локальной разработки без Docker: Python 3.11, PostgreSQL 15.

Инструкция по запуску

Вариант 1: Запуск через Docker 

Если по каким-то причинам автоматический скрипт не работает, выполните шаги вручную:
Убедитесь, что Docker Desktop запущен.
Скачайте и установите Ollama (если её нет) с официального сайта: https://ollama.com/download
Запустите Ollama в отдельном терминале: ollama serve
В корне проекта выполните: docker-compose up --build
Дождитесь появления в логах строки Application startup complete.
После этого запустить http://127.0.0.1:5500/frontend/index.html с помощью live server
Бэкенд доступен по адресу: http://localhost:8000/docs

Вариант 2: Локально (Без Docker)

Создайте и активируйте виртуальное окружение: python -m venv .venv
Активируйте его: source .venv/bin/activate (для Mac/Linux)
Установите зависимости: pip install -r requirements.lock
Создайте БД alfa_data в PostgreSQL и примените миграции:
psql -U postgres -d alfa_data -f backend/database/schema.sql
psql -U postgres -d alfa_data -f seed.sql
Запустите сервер: uvicorn backend.main:app --reload
Запустите фронтенд через Live Server (в VS Code) или откройте index.html в браузере.
Не забудьте, что для работы ИИ должна быть запущена Ollama (ollama serve).

Конфигурации и переменные окружения
Все настройки вынесены в файл docker-compose.yml (для Docker) или .env (для локального запуска).
DB_HOST — хост базы данных (по умолчанию db в Docker, localhost локально).
DB_PORT — порт базы данных (5432).
DB_NAME — имя базы данных (alfa_data).
DB_USER — пользователь БД (postgres).
DB_PASSWORD — пароль БД (Tatinkom92).
OLLAMA_BASE_URL — адрес Ollama (http://host.docker.internal:11434).
OLLAMA_MODEL — название модели (qwen3.5:4b).

Фиксация версий (Lock-файлы)

Python: В Dockerfile используется фиксированный образ python:3.11-slim.

Зависимости: В проекте есть requirements.txt (список основных библиотек) и requirements.lock (полный список зависимостей с точными версиями, сгенерированный через pip freeze). В Dockerfile установка идет из requirements.lock.

JS: Все библиотеки (Tailwind, FontAwesome) подключены через CDN с фиксированными версиями.

БД: Используется образ postgres:15-alpine.

Описание используемых компонентов

Backend (FastAPI):
backend/main.py — роутинг, эндпоинты, CORS.
backend/database/ — работа с PostgreSQL (пул соединений, SQL-запросы).
backend/services/calculate_score.py — rule-based скоринговая модель.
backend/llm/ — модуль интеграции с Ollama (промпты, guardrails, fallback).
backend/schemas.py — Pydantic-схемы для валидации данных.

Frontend (Vanilla JS):
js/api.js — слой работы с API (fetch).
js/navigation.js — логика переходов между экранами.
js/scoring.js — логика отправки на скоринг и получения ответа ИИ.
js/manager.js — дашборд менеджера.
js/state.js — глобальное состояние (appState).

Пошаговый сценарий проверки (End-to-End)

Вход: Откройте фронтенд. На экране входа выберите аккаунт Иван Иванов.

Личный кабинет: Вы попадаете в кабинет клиента. Нажмите Создать заявку.

Выбор компании: Выберите из списка ИНН 7701234567 (ООО Ромашка) и нажмите Найти. Система подтянет данные из мока ЕГРЮЛ.

Цель: Выберите Кассовый разрыв, нажмите Продолжить.

Калькулятор: Подвиньте ползунки суммы и срока. Включите стресс-тест (галочка +3%). Нажмите Отправить в ИИ-скоринг.

Скоринг: Подождите несколько секунд. Система сделает запрос к Ollama, и на экране появится Совет от ИИ-ассистента (текст, сгенерированный нейросетью).

Отправка менеджеру: Нажмите Отправить заявку менеджеру. Вы попадете на экран результата (статус Ожидайте).

Дашборд менеджера: В верхнем меню нажмите Менеджер. Вы увидите заявку Ивана Иванова.

Решение: Кликните на заявку, прочитайте ИИ-резюме, напишите комментарий (например, Требуется залог) и нажмите Одобрить (или Отклонить).

Результат: Вернитесь на экран Результат (или нажмите Обновить статус). Вы увидите, что заявка одобрена (или отклонена), а также объяснение от ИИ с учетом комментария менеджера.
