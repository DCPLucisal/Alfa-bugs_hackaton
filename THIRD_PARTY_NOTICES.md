
1. Библиотеки и фреймворки (Backend)
FastAPI (MIT License). Веб-фреймворк для создания REST API.
Uvicorn (BSD 3-Clause License). ASGI-сервер для запуска FastAPI.
PostgreSQL (PostgreSQL License). Реляционная база данных.
psycopg2-binary (LGPL with exceptions). Драйвер для подключения к PostgreSQL из Python.
Pydantic (MIT License). Библиотека для валидации данных на основе типов Python.
python-dotenv (BSD 3-Clause License). Загрузка переменных окружения из файла .env.
bcrypt (Apache License 2.0). Библиотека для хеширования паролей.
httpx (BSD 3-Clause License). HTTP-клиент для взаимодействия с API Ollama.

2. Библиотеки и фреймворки (Frontend)
Tailwind CSS (MIT License). CSS-фреймворк для стилизации интерфейса (подключен через CDN).
Font Awesome (Free License). Набор иконок для интерфейса (подключен через CDN).
Google Fonts (Inter). Шрифт для интерфейса (подключен через CDN).

3. Искусственный интеллект и модели
Ollama (MIT License). Локальный сервер для запуска больших языковых моделей (LLM).
Модель: Qwen 3.5 (4B параметров). Лицензия: Apache 2.0. Используется для генерации текстовых объяснений скоринга для клиента и резюме для менеджера.
Все модели работают локально (без обращения к платным API типа OpenAI или YandexGPT).

4. Данные
Все данные в системе являются синтетическими (сгенерированы командой для демонстрации).
Реальные персональные данные (ПДн) не используются.
Данные о клиентах, компаниях, кредитной истории и финансовых показателях вымышлены.

5. Смоделированные интеграции (Моки)
В соответствии с условиями хакатона, доступ к корпоративным системам банка запрещен. Следующие интеграции смоделированы (имитируются через локальные заглушки и базу данных):

ЕГРЮЛ / ЕГРИП (ФНС). Имитация получения данных о компании по ИНН (название, ОКВЭД, адрес, статус).
Бюро кредитных историй (БКИ). Имитация получения кредитной истории (наличие просрочек, кредитный рейтинг).
Скоринговая система банка. Реализована как rule-based модель на Python (без использования закрытых ML-моделей банка).
Интернет-банк (Альфа-Бизнес). Имитация авторизации и получения списка компаний клиента (без реального OAuth).
Электронная подпись (УКЭП). Имитация подписания кредитного договора через ввод СМС-кода.
